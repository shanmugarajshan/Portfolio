# Shanmugaraj D — Portfolio

React (Create React App). No extra libraries: all animation is CSS + a small scroll hook.

    npm install
    npm start        # dev server
    npm run build    # production build in /build

Edit your content in `src/data.js` (skills, jobs, projects, contact links).
Resume file served at `/Shanmugaraj-Resume.pdf` (replace `public/Shanmugaraj-Resume.pdf` to update).
